# 文件清单

## 核心程序文件

### 主程序
- **main.py** - 核心计算引擎（430行）
  - 包含所有评分计算逻辑
  - Score类：评分存储和计算
  - Member类：员工信息和评分
  - 主要函数：init、check_file、computed、out

- **gui_main.py** - GUI界面程序（213行）
  - 基于tkinter的用户界面
  - 文件选择、进度显示、结果查看

- **build_gui_exe.py** - EXE打包脚本（163行）
  - 使用PyInstaller打包
  - 生成独立可执行文件

### 测试脚本
- **测试新评价文件.py** - 功能测试脚本
  - 使用测试文档进行验证
  - 显示前15条结果

- **检查符合要求.py** - 需求验证脚本
  - 验证人员配置
  - 验证权重规则
  - 验证输出格式
