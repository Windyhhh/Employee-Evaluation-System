## 技术实现

### 核心算法
```
评分分类 → 维度平均 → 权重计算 → 排序输出
```

### 关键特性
1. **多维度评分**：三个独立的评分维度，分别计算平均值
2. **角色分类**：根据员工角色应用不同的权重规则
3. **双重身份**：王岳珑和王丽丽的评分同时计入两个权重
4. **灵活配置**：所有规则都可通过Excel配置文件修改

## 权重规则

### 组长/小队长
```
最终得分 = 处长(40%) + 副处长(30%) + 其他人员互评(30%)
```

### 普通员工
```
最终得分 = 处长(20%) + 副处长(30%) + 组长(30%) + 其他人员互评(20%)
```

## 特殊处理

### 王岳珑和王丽丽
- 身份：副处长 + 组长
- 处理：评分同时计入副处长权重和组长权重
- 输出：不出现在被评分人列表中（他们是评分人）
