# 2025年度架构与技术管理处员工评价系统

## 系统概述

本系统是一个基于Excel的员工评价管理系统，用于计算和统计2025年度架构与技术管理处全体员工的最终评分，并按分数从高到低进行排序。

## 核心功能

### 1. 多维度评分汇总
- 支持三个评分维度（score1、score2、score3）
- 每个维度可代表不同的评价标准或评价时间段
- 系统自动计算每个维度的平均分，再取总平均

### 2. 角色分类评分
系统将员工分为两类，采用不同的权重规则：

#### 组长/小队长
- **权重配置**：处长(40%) + 副处长(30%) + 其他人员互评(30%)
- **评分来源**：
  - 处长评价：孙炎森
  - 副处长评价：王岳珑、王丽丽
  - 其他人员互评：除处长、副处长外的所有人

#### 普通员工
- **权重配置**：处长(20%) + 副处长(30%) + 组长(30%) + 其他人员互评(20%)
- **评分来源**：
  - 处长评价：孙炎森
  - 副处长评价：王岳珑、王丽丽
  - 组长评价：所属组的组长
  - 其他人员互评：除处长、副处长、所属组长外的所有人

### 3. 特殊角色处理
**王岳珑和王丽丽的双重身份**：
- 王岳珑：副处长 + 业务架构组组长
- 王丽丽：副处长 + 技术管理组组长

对于他们所在组的普通员工，他们的评分被**同时计入副处长评价和组长评价**：
- 作为副处长：计入副处长评价权重(30%)
- 作为组长：计入组长评价权重(30%)

## 文件说明

### 配置文件
- **人员配置表2025.xlsx**：包含所有员工的基本信息和角色分配
  - Sheet1：人员配置（职能组、组长、员工层级）
  - Sheet2：分数配置（评分标准映射）
  - Sheet3：角色配置（权重规则）

### 输入文件
- **2025年度架构与技术管理处员工评价表-[姓名].xlsx**：每个评分人的评价表
  - 包含对所有被评分人的三维度评分

### 输出文件
- **2025年度架构与技术管理处人员评价汇总表.xlsx**：最终评分结果
  - 包含31名员工的最终得分和排序

## 使用方法

### 方式一：使用GUI程序
1. 运行 `dist\员工评价管理系统.exe`
2. 选择配置文件（人员配置表2025.xlsx）
3. 选择评价文件所在文件夹
4. 点击"开始计算"
5. 查看输出文件

### 方式二：使用命令行
```bash
python main.py
```

## 核心算法

### 评分计算流程
1. **读取配置**：加载人员配置、分数配置、角色配置
2. **读取评价**：遍历所有评价文件，提取评分数据
3. **分类评分**：根据评分人和被评分人的角色，将评分分类到不同的评分来源
4. **计算平均**：对每个评分来源的三个维度分别计算平均分
5. **加权求和**：根据员工角色，使用对应的权重规则计算最终得分
6. **排序输出**：按最终得分从高到低排序，输出到Excel文件

### 评分分类逻辑
```
if 评分人是处长:
    → 计入处长评价(score[0])
elif 评分人是被评分人所在组的组长:
    → 计入组长评价(score[2])
    if 组长同时是副处长(王岳珑或王丽丽):
        → 也计入副处长评价(score[1])
elif 评分人是副处长(王岳珑或王丽丽):
    → 计入副处长评价(score[1])
else:
    if 被评分人和评分人都是普通员工:
        → 计入其他人员互评(score[4])
```

## 主要文件

- **main.py**：核心计算引擎
- **gui_main.py**：GUI界面程序
- **build_gui_exe.py**：EXE打包脚本
- **测试新评价文件.py**：测试脚本

## 注意事项

1. 评价文件必须包含"员工评价表"工作表
2. 人员配置表中的角色必须准确
3. 评分标准映射必须与评价表中的标签一致
4. 王岳珑和王丽丽不应出现在最终输出的被评分人列表中（他们是评分人）
