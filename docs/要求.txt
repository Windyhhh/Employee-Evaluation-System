|项目|详情|
| ---- | ---- |

## 三、各部分作业问题
### 第1部分 — Hadoop环境（20分）
1. 请说明在安装Hadoop之前，你做了哪些前置检查，前置条件或依赖准备。请解释你使用的命令以及具体操作方法。
2. 请展示你的Hadoop NameNode UI截图（http://127.0.0.1:9870）以及DataNode的主机名。（你的DataNode主机名是否与你虚拟机名字一致？）
3. 说明你的Hadoop部署模式：伪分布式（pseudo-distributed）还是集群模式（cluster mode）。
4. 请列出你修改过的关键配置文件（例如core-site.xml、hdfs-site.xml等），并解释其中的重要设置项。
5. 说明你在本机上如何启动和停止Hadoop。请写出命令行示例。
6. 可选：说明你在安装或配置过程中遇到的任何问题，以及你是如何解决这些问题的。

### 第2部分 — HDFS操作（20分）
（说明：学生必须将自己的数据集目录上传到HDFS，需提供目录结构、副本信息、块详情及指定文件空间占用情况）
1. 请提供你上传到HDFS后的项目目录结构。
2. 请展示你的项目文件的副本（replication）信息。
3. 请提供指定文件tracebench/AN_Data_corruptBlk_r_00FDN_30C_1to19B_0to120INT_15RT_5WT/event.csv的块（block）信息，包括：块数量、块ID。
4. 请提供你的最终数据集在HDFS中的空间占用情况（total size occupied）。包括所使用的命令、输出结果，并解释如何理解这个空间占用。
5. 请写出你如何将项目上传到HDFS的命令。包括命令行以及Hadoop返回的输出信息。
6. 说明你在将文件上传到HDFS时遇到的任何问题，以及你是如何解决这些问题的。

### 第3部分 — MapReduce编程与调试（40分）
1. 请说明你的整体MapReduce方法，包括：如何从HDFS读取数据集、如何为每个任务提取OpName和Description、如何生成eventName、如何根据全局eventId表获取eventId信息。
2. 请说明你对每个taskID的标注逻辑：如何判断任务为normal还是abnormal、如何处理AN_/COM_类型的trace以及description字段信息。
3. 请提供你的MapReduce代码片段或伪代码，展示：Mapper的输入、输出和逻辑；Reducer的输入、输出和逻辑。
4. 说明你如何在Hadoop上运行MapReduce作业：包括提交命令行（hadoop jar ...）、描述HDFS中的输入/输出路径。
5. 提供作业执行日志/输出验证：包括输出文件中的示例行：label, taskID, eventID1, eventID2,...
6. 提供输出验证：说明你如何验证输出的正确性。
7. 说明你在编写或运行MapReduce过程中遇到的任何问题，以及你是如何解决这些问题的。
