## 核心算法

### 1. 初始化阶段
```
init()
├─ 读取配置文件
├─ 加载人员配置（Sheet1）
├─ 加载分数配置（Sheet2）
├─ 加载角色配置（Sheet3）
└─ 初始化MERITS_MAP（员工对象字典）
```

### 2. 评分读取阶段
```
check_file()
├─ 遍历所有评价文件
├─ 提取评分人信息
├─ 提取被评分人信息
└─ 调用computed()处理每个评分
```

### 3. 评分分类阶段（computed函数）
```
for 每个评分:
    if 评分人是处长:
        → score[0] += 评分
    elif 评分人是被评分人所在组的组长:
        → score[2] += 评分
        if 组长同时是副处长:
            → score[1] += 评分
    elif 评分人是副处长:
        → score[1] += 评分
    else:
        if 被评分人和评分人都是普通员工:
            → score[4] += 评分
```

### 4. 计算阶段（return_excel函数）
```
for 每个员工:
    # 计算每个评分来源的平均分
    director_score = (score1[0] + score2[0] + score3[0]) / 3
    vice_director_score = (score1[1] + score2[1] + score3[1]) / 3
    group_leader_score = (score1[2] + score2[2] + score3[2]) / 3
    other_member_score = (score1[4] + score2[4] + score3[4]) / 3
    
    # 根据员工角色应用权重
    if 员工是组长或小队长:
        total = director × 0.4 + vice_director × 0.3 + other_member × 0.3
    else:
        total = director × 0.2 + vice_director × 0.3 + group_leader × 0.3 + other_member × 0.2
```

### 5. 输出阶段
```
out()
├─ 创建输出Excel文件
├─ 写入所有员工的评分数据
├─ 按最终得分排序
└─ 保存文件
```

## 关键特性

### 多维度评分
- 支持三个独立的评分维度
- 每个维度可代表不同的评价标准
- 最终分数是三个维度的平均值

### 双重身份处理
王岳珑和王丽丽既是副处长，也是组长：
- 他们的评分被同时计入两个权重
- 对于他们所在组的普通员工，这两个权重都会被应用

### 灵活的权重配置
- 权重规则存储在Excel配置文件中
- 可以动态修改，无需改代码
- 支持不同角色的不同权重

## 文件格式要求

### 评价表格式
```
Row 2: 评分人信息
  Col 6: 评分人名字
  Col 7: 评分人职能组
  Col 8: 评分人层级

Row 4+: 被评分人评分
  Col 2: 被评分人名字
  Col 5-7: 三维度评分（文本标签）
```

### 配置表格式
```
Sheet1: 人员配置
  Col 1: 职能组
  Col 2: 职能组组长
  Col 3: 考评对象
  Col 4: 员工层级

Sheet2: 分数配置
  Row 2-4: 三个维度的评分标准映射

Sheet3: 角色配置
  Row 2: 普通员工权重
  Row 3: 组长/小队长权重
```
