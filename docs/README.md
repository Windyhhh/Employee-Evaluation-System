# 2025年度架构与技术管理处员工评价系统

## 📋 项目概述

这是一个完整的员工评价管理系统，用于计算和统计2025年度架构与技术管理处全体员工的最终评分。

**项目状态**：✅ 已完成并通过测试

## 🎯 核心功能

- ✅ **多维度评分**：支持3个独立的评分维度
- ✅ **多角色权重**：组长/小队长 vs 普通员工的不同权重规则
- ✅ **特殊身份处理**：王岳珑、王丽丽的双重身份（副处长+组长）
- ✅ **自动汇总排序**：自动分类、计算、排序
- ✅ **友好界面**：GUI程序和独立EXE可执行文件
- ✅ **灵活配置**：所有规则都可通过Excel配置文件修改

## ⚙️ 权重规则

### 组长/小队长
```
最终得分 = 处长评价 × 40% + 副处长评价 × 30% + 其他人员互评 × 30%
```

### 普通员工
```
最终得分 = 处长评价 × 20% + 副处长评价 × 30% + 组长评价 × 30% + 其他人员互评 × 20%
```

## 🔧 配置修改

编辑 `人员配置表2025.xlsx` 的以下工作表：

- **Sheet1**：人员配置（职能组、组长、员工层级）
- **Sheet2**：分数配置（评分标准映射）
- **Sheet3**：角色配置（权重规则）
