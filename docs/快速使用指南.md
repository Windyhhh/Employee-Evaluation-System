# 快速使用指南

## 系统要求
- Windows 7 及以上
- 无需安装Python（EXE版本）

## 快速开始

### 步骤1：准备文件
1. 确保有以下文件：
   - `人员配置表2025.xlsx` - 人员和权重配置
   - 多个 `2025年度架构与技术管理处员工评价表-[姓名].xlsx` - 评价表

2. 将所有评价表放在同一个文件夹中

### 步骤2：运行程序
双击 `dist\员工评价管理系统.exe`

### 步骤3：配置参数
1. **选择配置文件**：点击"浏览"选择 `人员配置表2025.xlsx`
2. **选择评价文件夹**：点击"浏览"选择包含所有评价表的文件夹
3. **点击"开始计算"**：程序开始处理

### 步骤4：查看结果
计算完成后，在同一文件夹中生成：
- `2025年度架构与技术管理处人员评价汇总表.xlsx`

## 输出文件说明

### 评分汇总表结构
| 列 | 说明 |
|----|------|
| 排名 | 按最终得分排序 |
| 职能组 | 员工所属部门 |
| 考评对象 | 员工姓名 |
| 员工层级 | 组长/小队长/普通员工 |
| 处长评价 | 处长的评分 |
| 副处长评价 | 副处长的评分 |
| 组长评价 | 所属组长的评分 |
| 其他人员互评 | 其他员工的评分 |
| 总分 | 最终得分 |

## 权重规则

### 组长/小队长
```
最终得分 = 处长评价 × 40% + 副处长评价 × 30% + 其他人员互评 × 30%
```

### 普通员工
```
最终得分 = 处长评价 × 20% + 副处长评价 × 30% + 组长评价 × 30% + 其他人员互评 × 20%
```

## 常见问题

### Q: 为什么王岳珑和王丽丽不在输出结果中？
A: 他们是副处长和组长，属于评分人，不是被评分人。

### Q: 如何修改权重规则？
A: 编辑 `人员配置表2025.xlsx` 的 Sheet3（角色配置）

### Q: 如何修改人员配置？
A: 编辑 `人员配置表2025.xlsx` 的 Sheet1（人员配置）

### Q: 评分标准如何映射？
A: 编辑 `人员配置表2025.xlsx` 的 Sheet2（分数配置）

## 技术支持

如有问题，请检查：
1. 配置文件是否正确
2. 评价文件格式是否符合要求
3. 人员名称是否一致
4. 评分标签是否与配置匹配
